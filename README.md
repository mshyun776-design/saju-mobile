# 별담 운세

한국 음력·절기·간지를 계산해 일간·월간·연간 생활 점검 리포트를 제공하는 모바일 웹사이트입니다. 교육·오락용 전통 해석이며, 미래 예측·의료 진단·투자 수익 보장을 제공하지 않습니다.

접속: https://mshyun776-design.github.io/saju-mobile/

## 이용 방법

1. **나의 운세 이야기 시작하기** → 회원가입에서 이메일·비밀번호(6자 이상)를 입력합니다.
2. 확인 메일·인증번호 없이 Supabase Auth가 실제 가입·자동 로그인을 처리합니다. 기존 가입자는 로그인 탭을 사용합니다.
3. 별명(선택), 생년월일(YYYY-MM-DD), 양력/한국 음력, 음력 윤달, 출생 시각을 입력합니다. 시각 모름을 선택할 수 있습니다.
4. 일간·월간·연간 탭, 조회 날짜, 이전·다음·오늘 버튼으로 기간을 변경합니다.
5. 분야별 접기·펼치기, 시간 흐름, 실천 체크리스트와 리포트 복사를 이용합니다.

별명·출생 정보·운세 결과는 서버나 브라우저 저장소에 저장하지 않고 페이지 메모리에서만 처리합니다. 새로고침 시 재입력합니다. 로그아웃 시 개인 결과와 입력 화면도 초기화합니다. 비밀번호는 별도 보관하지 않으며 Supabase 표준 로그인 세션만 `byuldam-auth` 키로 유지합니다. 공용 기기에서는 사용 후 로그아웃하세요. 별도의 사용자 데이터 테이블을 만들지 않습니다.

## 계산 기준과 지원 범위

- 서비스 범위: 양력 **1900-01-01~2050-12-31**. 음력은 한국 달력 변환 후 이 양력 범위를 만족해야 합니다. 변환 라이브러리의 음력 상한은 **2050-11-18**입니다. 지원 범위 밖 날짜·존재하지 않는 윤달을 거부합니다.
- 기본: 한국 출생, 고정 한국 표준시 **UTC+9**. 과거 표준시 변경(UTC+8:30 등)·서머타임·경도·균시차·진태양시는 보정하지 않습니다. 과거 출생 시각은 사용자가 고정 KST로 환산해야 합니다. 해외 출생 계산은 지원하지 않습니다.
- 한국 음력: `korean-lunar-calendar 0.4.0`의 한국 음양력 데이터로 변환합니다. 중국 음력을 한국 음력의 대체로 사용하지 않습니다.
- 연주: 입춘의 정확한 시각. 월주: 12절의 정확한 시각. `lunar-javascript 1.7.7` 절기 계산은 UTC+8의 시계를 사용하므로 연·월주를 구할 때만 KST 입력에서 1시간을 빼서 비교합니다. 일주·시주는 이 보정에 따라 날짜가 밀리지 않게 별도로 KST 기준으로 계산합니다.
- 일주: KST **00:00** 경계. 23:00~23:59 야자시도 당일 일간을 유지하며, 시주의 천간은 해당 민간일 일간과 2시간 지지로 직접 계산합니다. 23시 일주 교체 학파와 다를 수 있습니다.
- 시각 모름: 시주를 추측하지 않습니다. 출생일 00:00~23:59의 연·월주를 대조해 절입일에 달라지는 기둥은 확정하지 않고 양쪽 후보와 이유를 표시합니다. 확정하지 못한 글자는 오행·합·충 계산에서 제외합니다.
- 오행: 확정된 천간·지지의 **대표 오행**을 각각 1개씩 집계합니다. 지장간·계절 가중치를 포함하지 않으며 신강·신약·용신을 의미하지 않습니다.
- 십신: 출생 일간과 조회 대표 천간의 오행 생극·음양 관계로 10가지 관계를 계산합니다. 비견/겁재, 식신/상관, 편재/정재, 편관/정관, 편인/정인을 구분합니다.
- 합·충: 조회 대표 지지와 확정 출생 지지의 육합 6쌍 및 충 6쌍만 대조합니다. 합화·삼합·형·파·해와 대운·용신·신살 등은 계산하지 않습니다.

## 리포트와 기간 범위

이름은 호칭에만 사용합니다. 같은 입력과 조회 기간에는 같은 규칙으로 같은 결과를 만듭니다. 난수·점수·성공 확률·유료 AI API를 사용하지 않습니다. 정해진 해석 문장을 실제 계산된 십신, 오행 분포, 합·충과 결합합니다. 실생활의 선택을 점검하는 제안이며 사건의 발생을 보장하지 않습니다.

- 일간: 선택일 일주, 08·14·20시 KST의 시주로 세 시점의 실천 힌트를 제시합니다. 각 시간대 전체를 한 시주로 대표하지 않습니다.
- 월간: 해당 월 **15일 정오 KST의 월주**가 핵심 주제의 대표입니다. 4·11·18·25일 정오의 월주를 별도로 계산해 네 번의 점검을 제공합니다. 이 날짜들은 달력의 모든 주차를 포괄하지 않습니다.
- 연간: 해당 해 **7월 1일 정오 KST의 연주**가 대표입니다. 각 월 15일 정오 KST의 월주로 12개 흐름을 구분합니다.

양력 연도·월의 경계와 입춘·절기의 간지 경계는 다릅니다. 특히 1월/입춘 전, 월초/절입 전은 대표 시점과 다를 수 있습니다. 대표 간지를 기간 전체에 동일하게 적용되는 사실처럼 읽지 마세요. 세부 날짜는 일간 탭에서 조회할 수 있습니다. 공식 천문 역서의 인증을 받은 서비스가 아니며, 전문 만세력의 판정 체계와 차이가 있을 수 있습니다.

## 개발·배포

```sh
npm ci
npm test
npm run build
```

HTML/CSS/JavaScript 정적 사이트입니다. 프런트엔드 패키지는 `package-lock.json`에 고정하고, 브라우저 번들을 `app.js`로 함께 배포합니다. CDN·웹폰트·유료 API 없이 동작합니다(로그인에는 Supabase 네트워크 연결 필요). HTML의 모든 자산은 상대 경로로 참조합니다. GitHub Pages: `main` 브랜치의 `/ (root)`를 배포합니다. 저장소 하위 경로의 화면 이동도 동일 HTML에서 처리합니다.

프런트엔드에는 Supabase 공개용 publishable 키만 포함합니다. 관리자 키·service_role 키·개인 토큰은 포함하지 않습니다. HTML에 삽입되는 이름은 이스케이프합니다. 기존 실습 프로젝트를 재사용했으며 인증 데이터 외 별도 DB 변경은 없습니다. 이메일/비밀번호 가입이므로 리디렉션 인증 URL은 사용하지 않습니다(`detectSessionInUrl:false`). 기존 프로젝트의 Site URL을 덮어쓰지 않습니다.
